# saleVoucher_EC_23HTTT

“Xây dựng hệ thống thương mại điện tử bán voucher giảm giá trực tuyến”

## Môi trường chạy

- Frontend React + Vite + Tailwind: `http://localhost:5173`
- Backend Express + Nodemon: `http://localhost:3001`

### Chạy local

Frontend:

- `cd frontend`
- `npm run dev`

Backend:

- `cd backend`
- `npm run dev`

Database:

- Migration mẫu nằm trong `database/migrations/001_init.sql`
- Supabase PostgreSQL cloud được cấu hình ở tầng backend/DAO (placeholder hiện tại).
